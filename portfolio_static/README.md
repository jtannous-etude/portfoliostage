# Portfolio (version statique, pages séparées)

Ce dossier contient une version statique (HTML + CSS) du portfolio, séparée en 4 pages :

- `index.html` — Accueil (hero, formations et expérience dépliante)
- `projects.html` — Liste des projets avec technologies sous forme de badges non-cliquables
- `skills.html` — Compétences et qualités
- `contact.html` — Coordonnées et téléchargement du CV

Remarques :

- Les images dans `assets/` sont des placeholders (SVG). Remplacez `photo.svg`, `diagramme.svg`, `projet_jeu.svg`, `site_musique.svg` et `linux.svg` par vos vraies images si nécessaire.
- Le fichier `assets/CV_Jean_Tannous.pdf` est actuellement un placeholder texte ; remplacez-le par votre vrai PDF pour que le bouton de téléchargement fonctionne.

Ouvrir localement : double-cliquez sur `index.html` ou ouvrez-le depuis votre navigateur (`C:\test\portfolio_static\index.html`).

Pour publier sur GitHub Pages : mettez ces fichiers dans la branche `gh-pages` ou dans la racine du repo et activez GitHub Pages dans les paramètres du dépôt.
